# assets

One folder per main page, then `img/` or `pdfs/`, then the folder for the
piece of work itself. If you're looking for a file, start with the page it
appears on.

    assets/
      home/                       index.html
        img/profile/              headshot + portrait

      sarahs-social-strategy/     sarahs-social-strategy/index.html
        img/carousel/             Instagram carousel slides
        img/flyer/                agency flyers

      writing-preceptorship/      writing-preceptorship/writing-resources.html
        img/handouts/             student handouts

      projects/                   projects/*
        img/sitcoms-presentation/ Sitcoms in Macon slides
        pdfs/digital-cartography/ Digital Cartography Project documents

Adding a new page: make `assets/<page-name>/img/` for it and keep its files
there, so nothing has to be untangled later.
